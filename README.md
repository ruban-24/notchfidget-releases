# Notch Fidget releases

Downloads for [Notch Fidget](https://github.com/ruban-24/notchfidget-releases/releases/latest): tiny toys you can feel on your MacBook's trackpad, opened from the notch.

**[Download the latest version](https://github.com/ruban-24/notchfidget-releases/releases/latest/download/NotchFidget.dmg)** (macOS 14 or later). Open the disk image and drag Notch Fidget into Applications.

The app's source isn't published here; this repository only hosts the signed, notarized installers.
